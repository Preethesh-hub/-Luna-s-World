# Luna's World 🌙✨

**Live Website:** [https://preethesh-hub.github.io/-Luna-s-World/](https://preethesh-hub.github.io/-Luna-s-World/)

*Stories, poetry, dreams, and worlds beyond imagination* by **G Daffini Shiyalin (Luna)**.

---

## Features
- **Editorial Night Library Theme**: Seamless archival cream light mode and nocturnal espresso/obsidian dark mode (`theme.css`, `theme.js`).
- **Original Poetry Collection**: 7 standalone poem pages (`poem-01.html` – `poem-07.html`, `warmth-that-burned.html`, `whispers-of-earth.html`).
- **Interactive Companions**:
  - Drifting golden fireflies that scatter gently away from the cursor.
  - Scroll-responsive Blue Morpho butterfly trio.
  - **Enchanted Wizard Owl** watcher (`assets/wizard-owl*.png`) with articulated real wings, synced sky/perch tail, pixel-matched eye blink, daytime drowsy / nighttime awakened states, Web Audio voice & flutter, hat starlight spells, and **Owl Post** surprise poem delivery.
- **Astra Guide**: Built-in floating site guide for exploring poems, stories, and Luna's works.

---

## Publishing on GitHub Pages
1. Open the repository on GitHub: [Preethesh-hub/-Luna-s-World](https://github.com/Preethesh-hub/-Luna-s-World)
2. Go to **Settings → Pages** and select **Source: GitHub Actions** (or **Deploy from a branch → `main` / `(root)`**).
3. In the repository homepage sidebar, click the gear icon next to **About** and set **Website** to:
   `https://preethesh-hub.github.io/-Luna-s-World/`
